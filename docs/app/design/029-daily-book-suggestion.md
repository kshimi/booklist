# 029: 日替わりの読書サジェスチョン

**Issue**: #29
**作成日**: 2026-03-26
**ステータス**: レビュー待ち

---

## 概要

日替わりで1冊のおすすめ本を表示する機能を追加する。
書籍はその日の日付をシードとした決定論的な選出ロジックで選ぶ。
おすすめには書籍基本情報に加え、Claude または Gemini による推薦コメントを表示する。

---

## 課題の整理

本プロジェクトは**静的SPA**であり、バックエンドサーバーを持たない。
AIコメントの生成タイミングと方式によって実現可能な設計が異なる。

| 課題 | 内容 |
|------|------|
| 日替わり選出 | 毎日1冊を自動的に選ぶロジックが必要 |
| AIコメント生成 | Claude/Gemini APIの呼び出しをどこで行うか |
| APIキー保護 | フロントエンドにAPIキーを含められない |

---

## 技術的アプローチ

### 1. 日替わり書籍の選出ロジック

日付をシードとした決定論的な選出をフロントエンドで行う。

```js
// daysSinceEpochを求め、books.lengthで剰余を取る
const epoch = new Date('2000-01-01');
const today = new Date();
const days = Math.floor((today - epoch) / 86400000);
const todaysBook = books[days % books.length];
```

- サーバーサイドの処理不要
- 同一日・同一データであれば全ユーザーが同じ書籍を見る（個人利用のため問題なし）
- `books.json` の件数変化で選出書籍が変わるが実用上問題なし

### 2. AIコメント生成方式の比較

#### 方式比較表

| 方式 | 説明 | メリット | デメリット |
|------|------|---------|-----------|
| **A: ビルド時一括生成** | `scripts/generate-ai-comments.js` で全書籍分のコメントを生成し `data/book-ai-comments.json` に保存 | APIキー不要（フロント）、高速表示 | 882件分の生成コスト大、初回実行時間長 |
| **B: ビルド時差分生成** | Aと同様だが未生成書籍のみ対象（増分対応） | コスト抑制、都度実行可能 | 全書籍カバーまで時間がかかる |
| **C: ランタイム呼び出し** | ブラウザから直接 Claude/Gemini API を呼び出す | 常に最新コメント | **APIキー露出リスクあり（採用不可）** |
| **D: コメントなしの書籍はフォールバック** | Bの変形。コメント未生成の場合はあらすじや書誌情報で代替表示 | 即座に稼働開始可能、段階的に拡充 | 初期はAI感が薄い |

#### 推奨方式: **B + D の組み合わせ**

- `scripts/generate-ai-comments.js`（新規スクリプト）でコメントを差分生成
- 生成済みコメントは `data/book-ai-comments.json` に保存（Git管理対象）
- フロントエンドはコメントが存在する場合に表示、なければあらすじ（book-metadata）で代替
- `enrich.js` と同様の手動実行モデルで運用

### データ構造: `book-ai-comments.json`

キーは `books.json` の `id` フィールド。

```json
{
  "9784774129846": {
    "comment": "Claudeによる推薦コメントテキスト...",
    "generatedAt": "2026-03-26",
    "model": "claude-opus-4-6"
  }
}
```

### generate-ai-comments.js の動作

```
data/books.json
data/book-ai-comments.json（既存データ。なければ空オブジェクト）
    │
    ▼ 対象書籍の特定
    │  ・差分モード: コメント未生成の書籍のみ（デフォルト）
    │  ・--all オプション: 全書籍を再生成
    │  ・--limit N オプション: N件のみ生成（コスト制御）
    │
    ▼ AIへのプロンプト送信
    │  ・タイトル・著者・ジャンル・あらすじ（book-metadata.json）を入力
    │  ・200字程度の推薦コメント生成を依頼
    │  ・APIキーは環境変数 ANTHROPIC_API_KEY または GEMINI_API_KEY から取得
    │
    ▼ book-ai-comments.json への保存
       ・取得結果を既存データとマージして保存
```

### UI: DailySuggestion コンポーネント

- 表示位置: ヘッダー直下、タブナビゲーション上
- 表示内容:
  - 「今日のおすすめ」見出し（日付付き）
  - 書影（book-metadata.json の coverUrl があれば表示）
  - タイトル・著者名（クリックで書籍詳細モーダルを開く）
  - ジャンルバッジ
  - AIコメント（未生成の場合はあらすじで代替）
- 折りたたみ可能（デフォルト展開）
