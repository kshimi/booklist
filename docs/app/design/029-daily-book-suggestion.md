# 029: 日替わりの読書サジェスチョン

**Issue**: #29
**作成日**: 2026-03-26
**ステータス**: 承認済み

---

## 概要

日替わりで1冊のおすすめ本を表示する機能を追加する。
書籍はその日の日付をシードとした決定論的な選出ロジックで選ぶ。
おすすめには書籍基本情報に加え、Gemini による推薦コメント（日本語）を表示する。

---

## 課題の整理

本プロジェクトは**静的SPA**であり、バックエンドサーバーを持たない。
AIコメントの生成タイミングと方式によって実現可能な設計が異なる。

| 課題 | 内容 |
|------|------|
| 日替わり選出 | 毎日1冊を自動的に選ぶロジックが必要 |
| AIコメント生成 | Gemini APIの呼び出しをどこで行うか |
| APIキー保護 | フロントエンドにAPIキーを含められない |

---

## 技術的アプローチ

### 1. 日替わり書籍の選出ロジック

日付をシードとした決定論的な選出をフロントエンドで行う。

```js
// daysSinceEpochを求め、books.lengthで剰余を取る
const epoch = new Date('2000-01-01');
const today = new Date();
const days = Math.floor((today - epoch) / 86400000);
const todaysBook = books[days % books.length];
```

- サーバーサイドの処理不要
- 同一日・同一データであれば全ユーザーが同じ書籍を見る（個人利用のため問題なし）
- `books.json` の件数変化で選出書籍が変わるが実用上問題なし
- この選出ロジックを使ってスクリプト側でも将来日付を計算できるため、「今日から N 日分」の範囲指定生成が可能

### 2. AIコメント生成方式

#### 方式比較表

| 方式 | 説明 | メリット | デメリット |
|------|------|---------|-----------|
| **A: ビルド時一括生成** | 全書籍分のコメントを生成し保存 | APIキー不要（フロント）、高速表示 | 882件分の生成コスト大、初回実行時間長 |
| **B: ビルド時差分生成** | 未生成書籍のみ対象（増分対応） | コスト抑制、都度実行可能 | 全書籍カバーまで時間がかかる |
| **C: ランタイム呼び出し** | ブラウザから直接 API を呼び出す | 常に最新コメント | **APIキー露出リスクあり（採用不可）** |
| **D: コメントなし書籍のフォールバック** | Bの変形。コメント未生成の場合はあらすじで代替表示 | 即座に稼働開始可能、段階的に拡充 | 初期はAI感が薄い |

#### 採用方式: **B + D の組み合わせ**

- `scripts/generate-ai-comments.js`（新規スクリプト）でコメントを差分生成
- 生成済みコメントは `data/book-ai-comments.json` に保存（Git管理対象）
- フロントエンドはコメントが存在する場合に表示、なければあらすじ（book-metadata）で代替
- `enrich.js` と同様の手動実行モデルで運用
- 日付ベースの選出ロジックを利用し、**当日から N 日分**（または N 週間・N ヶ月）など範囲を指定した生成に対応

## 確定事項

| 項目 | 決定内容 |
|------|---------|
| 使用モデル | **Gemini のみ**（`@google/generative-ai` を新規導入）。無料枠のみ利用。無料枠リミット到達時は処理を中断し、直前まで生成したコメントを保存して終了する |

| 表示位置 | **常時表示**（ヘッダー直下、タブナビゲーション上） |

| 範囲指定オプション | `--days N` オプションで「今日から N 日後まで」の書籍を対象に生成（デフォルト: 差分のみ） |

### データ構造: `book-ai-comments.json`

キーは `books.json` の `id` フィールド。

```json
{
  "9784774129846": {
    "comment": "Geminiによる推薦コメントテキスト（日本語）...",
    "generatedAt": "2026-03-26",
    "model": "gemini-1.5-flash"
  }
}
```

### generate-ai-comments.js の動作

```
data/books.json
data/book-metadata.json
data/book-ai-comments.json（既存データ。なければ空オブジェクト）
    │
    ▼ 対象書籍の特定
    │  ・デフォルト: コメント未生成の書籍のみ（差分モード）
    │  ・--days N: 今日から N 日後までの日替わり対象書籍を算出し、未生成のものを対象とする
    │  ・--all: 全書籍を再生成
    │
    ▼ Gemini API 呼び出し
    │  ・タイトル・著者・ジャンル・あらすじ（book-metadata.json）を入力
    │  ・後述のプロンプトテンプレートで400字程度の推薦コメント生成を依頼
    │  ・APIキーは環境変数 GEMINI_API_KEY から取得
    │  ・429 (quota exceeded) を受信した場合は即座に処理を中断
    │
    ▼ book-ai-comments.json への保存
       ・1件生成するたびに都度ファイルに書き込む（中断時のデータ損失を防ぐ）
       ・取得結果を既存データとマージして保存
```

### プロンプトテンプレート

```
以下の本について、読者の興味を引く推薦コメントを日本語で400字程度で書いてください。
本の内容や特徴を簡潔に伝え、どんな人に向いているかも含めてください。

タイトル: {title}
著者: {author}
ジャンル: {genre}
あらすじ: {description}

推薦コメントのみを出力してください（前置きや説明は不要です）。
```

- `{description}` が未取得の場合はあらすじ行を省略してプロンプトを送信する
- 出力は `comment` フィールドにそのまま格納する

### UI: DailySuggestion コンポーネント

- 表示位置: ヘッダー直下、タブナビゲーション上（常時表示）
- 表示内容:
  - 「今日のおすすめ」見出し（日付付き）
  - 書影（book-metadata.json の coverUrl があれば表示）
  - タイトル・著者名（クリックで書籍詳細モーダルを開く）
  - ジャンルバッジ
  - AIコメント（未生成の場合はあらすじで代替。あらすじもなければコメントエリアを非表示）
