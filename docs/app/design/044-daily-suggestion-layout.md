# 044: 今日のおすすめレイアウト見直し

**Issue**: #44
**作成日**: 2026-04-10
**ステータス**: レビュー待ち

---

## 概要

AIコメントが400字程度と長くなったことで、`DailySuggestion` コンポーネントのコメント表示エリアが `line-clamp-4` により文字切れしている。
コメント全文が表示できるようにレイアウトを見直す。

---

## 現状の問題

`src/components/DailySuggestion.jsx` のコメント表示部分:

```jsx
<p className="text-xs text-gray-700 mt-2 leading-relaxed line-clamp-4">
  {displayText}
</p>
```

- `line-clamp-4` により約4行で切り捨てられる
- AIコメントは400字程度のため、大半が表示されない

---

## 技術的アプローチ

### アプローチ比較表

| # | 方式 | 説明 | メリット | デメリット |
|---|------|------|---------|-----------|
| **A** | line-clamp 削除 | `line-clamp-4` を除去してコメント全文を表示 | 変更最小限 | カードが縦に長くなり書影との高さバランスが崩れる可能性 |
| **B** | 縦積みレイアウト | 上段に書影＋書誌情報、下段にコメント（幅いっぱい）の2段構成 | コメントに十分な横幅を確保 | レイアウト変更が大きい |
| **C** | 横並び＋コメント下配置 | 現在の横並びは維持しつつ、コメントをカード全幅の下段に移動 | 見た目のバランスが良い | 若干のリファクタが必要 |

### 採用方式: **C（横並び＋コメント下配置）**

- 上段: 書影（左）＋タイトル・著者・ジャンルバッジ（右）を横並びで維持
- 下段: コメントをカード全幅で表示（`line-clamp` なし）
- 変更箇所が少なく、既存のスタイルを最大限流用できる

#### 変更後のレイアウトイメージ

```
┌──────────────────────────────────────────────┐
│ 今日のおすすめ（4月10日）                        │
│ ┌────┐  タイトル                               │
│ │書影│  著者名                                 │
│ │    │  [ジャンル]                             │
│ └────┘                                        │
│ AIコメント全文がここに入ります。コメント全文が表示  │
│ されます。400字程度のテキストがそのまま表示され    │
│ ます。                                         │
└──────────────────────────────────────────────┘
```
