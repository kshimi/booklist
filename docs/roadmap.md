## 本書の運用

- **更新タイミング**（`~/.claude/workflow.md` "Progress & Roadmap Management"）— 起票時＝
  `/wf-plan` が作業単位表に `未着手` 行を追加／計画の変化＝Phase 3（`/spec-update`）／
  完了＝`/merge-cleanup` が状態を `完了` に更新
- **状態語彙**（5 語・絵文字は使わない）— `完了` / `進行中`（open かつ着手済み）/
  `未着手`（open だが未着手）/ `保留`（意図的に止めている・理由を備考に）/ `中止`
- **Issue 情報を手写ししない** — 本書は Issue 番号への参照のみを持つ。タイトル・状態の
  複製はしない（`gh issue list` と二重管理にしないため）
- **他文書との役割分担**
  - 本書 — 作業単位の計画と現在地
  - `docs/app/backlog.md` — 将来機能構想・未 Issue 化の既知課題・優先度メモ（Issue 化前の計画コンテンツ）
  - `PROJECT_STATE.md` — Web チャット（claude.ai）での要件相談用コンテキスト文書。進捗 2 節は本書への参照リンクに置換済み
  - `docs/app/design/` — Issue 単位の設計書
  - `docs/app/spec/` — 機能仕様・システム仕様
  - `CLAUDE.md` — プロジェクトの静的定義（目的・スコープ・設定）
